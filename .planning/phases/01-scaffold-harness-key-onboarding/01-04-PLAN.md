Contract this plan CREATES (01-07 global-setup and record test import it):
```typescript
// tests/replay/server.ts
export interface ReplayServer { url: string; close(): Promise<void> }   // url = 'http://127.0.0.1:<port>'
export function startReplayServer(opts: {
  fixturesDir: string            // tests/fixtures/claude
  logDir: string                 // where <n>.req.json goes in replay mode (test-results/replay)
  record?: boolean               // RECORD mode
  upstream?: string              // default 'https://api.anthropic.com'
  port?: number                  // default 0
}): Promise<ReplayServer>
```
Wire protocol:
- Client base URL: `${url}/s/<scenarioKey>` where scenarioKey = `<scenario>` or `<scenario>~<launchId>`. Fixture lookup uses the part before `~`; the request counter is keyed by the full scenarioKey (so every app launch starts at 0).
- Fixture file: `<fixturesDir>/<scenario>/<n>.res.json` = `{ "status": number, "headers": { "content-type": string }, "body": string }` (body is raw JSON or SSE text).
- Request log: `<n>.req.json` = `{ "method": string, "path": string, "body": unknown }` — NO headers. Replay mode writes to `<logDir>/<scenarioKey>/`; record mode writes next to the fixture.
- `GET /__log/<scenarioKey>?canary=<value>` → `{ requests: [{method, path, body}], sawCanary: boolean }` where sawCanary is true iff some request's `authorization` header === `Bearer <value>` or `x-api-key` === value. Header values are kept only in memory and never returned.
- Missing fixture → status 599, JSON `{ "type": "error", "error": { "type": "replay_missing", "message": "<scenario>/<n>" } }`.
</interfaces>
