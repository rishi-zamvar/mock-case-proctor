<feature>
  <name>LlmPort.interrupted for the Claude adapter</name>
  <files>src/main/agent/claudeLlm.ts, src/main/agent/claudeLlm.bargein.test.ts</files>
  <behavior>
    Use the sse.harness fetch stub with a per-event delay for the mid-stream case, as the existing abort test does:
    - Mid-stream abort, grill. Turn A completes (it has tool_use toolu_A). In turn B, abort after the first text delta, then call `llm.interrupted('First sentence.')`. Next, streamTurn C is requested. Its body.messages = [userA, asstA(tool_use), userB(tool_result toolu_A + proctor + candidate B), assistant text 'First sentence. [interrupted]', userC]. userC has NO tool_result block. `checkConversation(messages)` → [].
    - Completed-then-interrupted, grill (the replay case). Turn B streams fully: it has tool_use toolu_B, and remember() has already run. Then `interrupted('First sentence.')` REPLACES the last assistant message with the text-only one. In the next request the assistant is text-only (no toolu_B), userC has no tool_result, and checkConversation → [].
    - Empty spoken: `interrupted('')` → assistant text '… [interrupted]' (non-empty), and checkConversation → [].
    - Warm-up: abort warm-up turn 2 mid-stream, `interrupted('Nice.')` → the next warmupTurn request's messages alternate, and the assistant is 'Nice. [interrupted]'.
    - interrupted() with no turn in progress or remembered since the last call is a no-op. Calling it twice changes nothing the second time.
    - The aborted generator, when it resumes after interrupted(), does NOT also remember() the turn, so there is no duplicate. Guard with `if (!msg || signal.aborted) return`.
    - Logs carry no candidate or reply text (reuse the existing 'never logs' assertion style).
  </behavior>
  <implementation>
    - Closure state: `let last: { msgs: MessageParam[]; user: MessageParam; remembered: boolean; grill: boolean } | null = null`.
    - Set it at the start of each streamTurn/warmupTurn, after `user` is built: `last = { msgs: grillMsgs | warmMsgs, user, remembered: false, grill: true | false }`. After `remember(...)`, set `last.remembered = true`.
    - Change `if (!msg) return` to `if (!msg || signal.aborted) return` in both turns, and delete the Phase-7 ponytail comment.
    - `interrupted(spoken)`:
      `if (!last) return; const a = textOnlyAssistant(spoken.trim() || '…', true)`
      If `last.remembered`, set `last.msgs[last.msgs.length - 1] = a`; otherwise `last.msgs.push(last.user, a)`.
      If `last.grill`, set `pendingToolUseId = null`. Then `last = null`.
    - Add it to the returned object; LlmPort.interrupted is optional, so fakeLlm needs no change.
    - Commits: `test(07-05)` RED, then `feat(07-05)` GREEN, using `git commit -- <paths>`.
  </implementation>
</feature>
