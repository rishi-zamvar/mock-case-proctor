<objective>
The pure, testable heart of VIN-04 and of chunked transcription. It has four parts: a voiced-frame gate run before whisper, a hallucination and repetition cleaner run after whisper, a `filteredStt(inner)` wrapper that composes them around any SttPort, and an answer assembler that transcribes ~20 s chunks while the user is still talking and joins them on stop. It also extends the port contracts (SttPort result, and LlmPort.interrupted for barge-in) so wave-2 plans build against them.

Purpose: whisper hallucinates on every silent input, and `no_speech_thold` does not help (RESEARCH, measured). A 60 s one-shot pass takes about 3 s, so it must be chunked.
Output: four pure modules with tests, plus updated port types.
</objective>

// ports/index.ts
export type SttResult = { text: string; noAnswer?: boolean; voicedMs?: number }
export interface SttPort {
  transcribe(pcm16k: Float32Array, o?: { prompt?: string }): Promise<SttResult>
}
export interface LlmPort {
  ...existing
  /** Barge-in: the candidate cut the last warm-up/grill turn off. spokenText = only the sentences actually heard ('' if none). */
  interrupted?(spokenText: string): void
}

// stt/gate.ts
export const FRAME = 320            // 20 ms @ 16 kHz
export const VOICED_RMS = 0.02      // ponytail: absolute threshold; make it relative to the noise floor if AGC rooms trip it
export const MIN_VOICED_MS = 400
export function voicedMs(pcm: Float32Array, rms?: number): number

// stt/clean.ts
export function isHallucination(text: string): boolean
export function collapseRepeats(text: string): string
export function cleanTranscript(text: string): string   // '' if hallucination, else collapsed + trimmed

// stt/filtered.ts
export function filteredStt(inner: SttPort, o?: { log?: Pick<Logger, 'info'>; minVoicedMs?: number; rms?: number }): SttPort

// stt/answers.ts
export type AnswerResult = { text: string; noAnswer: boolean; voicedMs: number }
export function createAnswerAssembler(o: {
  stt: SttPort
  prompt(): string | undefined
  arrivalTimeoutMs?: number // default 5000
}): {
  chunk(answerId: string, idx: number, pcm: Float32Array): void
  finish(answerId: string | undefined, chunks: number): Promise<AnswerResult>
  reset(): void // drop every pending answer (session change)
}

<feature>
  <name>STT gate, cleaner, filtered wrapper and chunk assembler</name>
  <files>src/main/stt/{gate,clean,filtered,answers}.ts and their .test.ts files, src/main/ports/index.ts</files>
  <behavior>
    gate (voicedMs):
    - `new Float32Array(16000 * 3)` (zeros) → 0.
    - A 1 kHz sine at amplitude 0.5 for 1 s → 1000 (±20).
    - Uniform noise with RMS about 0.018 for 2 s → < 400. Seed it deterministically, with a simple LCG, not Math.random.
    - 300 ms of 0.5 sine inside 3 s of zeros → 300 (±20), which is below MIN_VOICED_MS.
    - A partial trailing frame is ignored.
    clean:
    - Each of 'Thank you.', ' you', ' .', ' dollars.', ' money.', 'Thanks for watching!', 'Transcription by CastingWords', '[BLANK_AUDIO]', '(silence)', '♪', '♪♪ ♪' → isHallucination true, cleanTranscript ''.
    - Normalisation lowercases and strips punctuation, brackets and whitespace, and compares only the whole output: 'Thank you for the question, retention is 85%.' is NOT a hallucination.
    - collapseRepeats('the churn the churn the churn is high') → 'the churn is high'.
    - collapseRepeats('so so so so we pass') → 'so we pass'.
    - A 2x repeat is kept: 'very very good' → unchanged.
    - An 8-gram repeated 3x collapses; a 9-gram repeated 3x is left alone.
    - The original casing and punctuation of the kept tokens are preserved.
    filteredStt:
    - On zeros, inner.transcribe is NOT called, and the result is { text:'', noAnswer:true, voicedMs:0 }.
    - On a voiced sine, inner is called with the same pcm and `{ prompt }` passed through. Inner 'Thank you.' → { text:'', noAnswer:true }. Inner ' Retention is 85%. ' → { text:'Retention is 85%.', noAnswer:false, voicedMs≈1000 }.
    - log.info is called with ('stt voiced', <number>) only. It never receives the transcript text; assert that no log argument contains 'Retention'.
    assembler:
    - Chunks 0, 1 and 2 arrive (one each of voiced, voiced, voiced). finish(id, 3) joins the inner texts in idx order with single spaces, even when the inner resolves chunk 1 before chunk 0, and voicedMs is the sum.
    - chunk() starts stt.transcribe immediately: by the time finish is called, chunk 0 has already been called.
    - finish(id, 2) before chunk 1 arrives waits for it. If it never arrives within arrivalTimeoutMs, it is treated as empty (use fake timers).
    - Every chunk returns noAnswer or '' → { text:'', noAnswer:true }.
    - finish(undefined, 0), the FakeStt path: calls stt.transcribe(new Float32Array(0), { prompt }) once and returns its text trimmed. noAnswer is true only if the text is empty.
    - An inner rejection on any chunk rejects finish with the same error, so the runner can show "transcription failed".
    - After finish, the answer's state is deleted. reset() drops pending answers, and a chunk for an unknown id after reset starts a fresh entry.
  </behavior>
  <implementation>
    - The gate is the RESEARCH Pattern 5 code verbatim (sum of squares per FRAME, sqrt, compare, count × 20 ms), with `rms` overridable.
    - The phrase set is a `Set` of normalised strings: lowercase, remove everything matching `[^a-z0-9]`. '♪' normalises to '', and an empty normalised output counts as a hallucination. Put a `ponytail:` comment on the list: extend it as new phrases are observed.
    - collapseRepeats: split on whitespace into tokens, and compare on the normalised token. For n from 8 down to 1, scan i; while tokens[i..i+n] equals the next n tokens twice more (3 or more consecutive copies), delete the extra copies. Repeat until nothing changes. Keep the first copy's original tokens.
    - The assembler keeps a `Map<answerId, { parts: Map<idx, Promise<SttResult>>; waiters }>`. `chunk` stores `stt.transcribe(pcm, { prompt: o.prompt() })`. The underlying adapter serialises calls; the assembler does not. `finish` waits per idx for arrival (a promise resolved by chunk() or by the timeout), then `Promise.all`.
    - Ports: add SttResult, widen SttPort.transcribe with the optional `o` and the SttResult return, and add the optional `interrupted?` to LlmPort exactly as in the interfaces block. FakeStt needs no change.
    - Commits: `test(07-02): ...` (RED), then `feat(07-02): ...` (GREEN). Use `git commit -- <paths>` with only this plan's files.
  </implementation>
