- transcript: `<ol data-testid="transcript">` with `<li data-speaker="interviewer|candidate">` per line; a visually-hidden `aria-live="polite"` `data-testid="live-region"` holding the latest interviewer line
- bottom bar: `talk-btn` ('Talk' / 'Done' while recording, aria-pressed), `answer-timer` (m:ss, visible while recording), `ready-btn` 'Ready — start presenting' (review only), `skip-warmup` 'Skip warm-up' (warmup only), `end-btn` 'End session'
- end confirm: `role="alertdialog"` `data-testid="end-confirm-dialog"` with the text 'End the session now? You will still get a scorecard.', buttons `end-confirm` and `end-cancel`
- scoring phase: `data-testid="scoring"` 'Scoring your session…' in the stage; talk disabled
Countdown: `remaining = view.reviewDeadline - (view.clockNow + (now() - receivedAt) * view.timeScale)`, where receivedAt = now() when the view prop changed. Clamp at 0 and re-render every 250 ms (setInterval, cleared on unmount). Format mm:ss with tabular digits.
Talk: not recording + canTalk → recording, startedAt = now(). Recording → onIntent({type:'answer', ms: Math.round(now()-startedAt)}) and stop. talk-btn is disabled when !canTalk && !recording. Space toggles via a window keydown listener when the event target is not an input/textarea/button (`e.preventDefault()`), so a focused button's own Space click does not double-fire.

- `full-transcript` list; `back-to-library` button
- if view.endedEarly: a notice `ended-early` 'Session ended early, partial scorecard.'
