Current Session.tsx facts: `remaining` is computed in render from `view.reviewDeadline - (view.clockNow + (now() - recv.at) * view.timeScale)`; a 250 ms setInterval forces re-render; `recv` re-anchors on every new view. Because main stamps clockNow before IPC delivery, a new view re-anchors slightly in the past, so the raw value can jump UP by (IPC delay × timeScale) — up to seconds at E2E time scales. Hence the monotonic clamp below.
