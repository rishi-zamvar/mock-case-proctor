Component contract (04-06 mounts it exactly like this):
```tsx
import DeckViewer, { deckLabel } from '../deck/DeckViewer'
<DeckViewer
  file={`app://bundle/cases/${view.card.id}/interviewee.pdf`}
  initialPage={view.deckPage}              // 1-based PDF page
  onPageChange={(page) => onIntent({ type: 'deckPage', page })}
/>
export function deckLabel(page: number, numPages: number): string
// deckLabel(1, n) === 'Prompt'; deckLabel(13, 32) === 'p. 12 / 31'
```
DOM contract (E2E in 04-07 and Session tests in 04-06 rely on these):
- root `data-testid="deck-viewer"` with `data-page={current}` `data-pages={numPages}` `data-zoom={zoom}`
- `data-testid="deck-page-indicator"` (class `tabular`) text = deckLabel(current, numPages)
- `data-testid="thumbs-toggle"` button with `aria-expanded`
- `<nav data-testid="deck-thumbs" hidden={!railOpen}>` with buttons `data-testid="thumb-{n}"`, `aria-current="page"` on the current one
- `data-testid="deck-pages"` scroll container; each page wrapped in `<div data-page-n={n}>`
- `data-testid="zoom-in"` / `data-testid="zoom-out"` buttons
- `data-testid="deck-error"` (role="alert") when the document fails to load

CSP today already allows `worker-src 'self' app: blob:` and `script-src 'self' 'wasm-unsafe-eval'`; a Vite-emitted worker under app://bundle is 'self'. Do not edit csp.ts unless 04-07's E2E proves a directive is missing.
