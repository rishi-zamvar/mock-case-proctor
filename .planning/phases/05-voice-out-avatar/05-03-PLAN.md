<feature>
  <name>Seq-ordered speech queue with marker acks and turn cancel</name>
  <files>src/renderer/src/speech/speechQueue.ts, src/renderer/src/speech/speechQueue.test.ts</files>
  <behavior>
Fake head (in the test file) MUST mirror TalkingHead: it keeps an internal FIFO of markers and audio items; when idle, a pushed marker fires synchronously; an audio item makes it busy until the test calls `endAudio()`, which then fires the following markers in order until the next audio item; `stopSpeaking()` clears the FIFO and the current audio, so pending markers NEVER fire; `isSpeaking` reflects busy. Fake tts returns deferred promises the test resolves.
Cases:
- enqueue s0,s1,s2 of one turn → synthesize called for all three in order immediately (pre-synthesis); synth(s1) is called before ack(s0)
- results resolved out of order (s1 before s0) → speakAudio still receives s0 then s1 then s2
- endAudio() after s0 → ack(t, 0, true) exactly once; then s1 plays; acks arrive in seq order
- onPlaying(true) fires once at s0's start marker; it does NOT go false between s0 and s1 while s1 is pending; onPlaying(false) after the last ack
- stats(): spoken lists {turnId, seq, visemes: data.visemes.length, startedAt, endedAt}; visemeCount sums only sentences that actually started
- cancel(t) while s0 plays and s1/s2 queued → stopSpeaking called once, ack(t,0,false), ack(t,1,false), ack(t,2,false), no ack(...,true) ever for them, isPlaying() false, onPlaying(false); a late synth result for s2 never reaches speakAudio
- cancel(t) when only unsynthesised items of t remain (nothing handed to head) → no stopSpeaking call, those seqs acked false
- cancel('other') leaves turn t untouched
- a new turn u enqueued after cancel(t) plays normally
- synth resolves {ok:false} for s1 → ack(t,1,false), s2 still plays
- items enqueued before `ready` resolves → no speakAudio until ready; if ready rejects → every queued seq acked false, no speakAudio
- clear() → behaves as cancel of every turn
- every seq is acked exactly once (assert via a counting ack across all cases)
  </behavior>
  <implementation>
Keep an ordered array of items `{ ev, synth: Promise<SynthResult>, state: 'pending'|'handed'|'started'|'done'|'dropped' }` and one promise chain for hand-off. On enqueue: start `tts.synthesize(ev.text)` immediately, then `chain = chain.then(() => handOff(item))`. handOff: `await o.ready` (a rejection drops the item with ack false); `const r = await item.synth`; return if dropped; on `!r.ok` ack false; else push `speakMarker(onStart)`, `speakAudio(r.data)`, `speakMarker(onEnd)` and mark handed. Make the start/end callbacks tolerate firing synchronously inside handOff (the fake and TalkingHead both do that when idle) and ignore dropped items. `finish(item, spoken)` is the only place acks happen; it guards against a second ack. cancel(turnId): if any handed/started item belongs to the turn, call `head.stopSpeaking()` once and drop + ack-false every handed/started item (of any turn, since the head queue is now empty); drop + ack-false every remaining item of that turn; prune done/dropped items; emit onPlaying(false) if the queue is now empty. Do not call tts.clear(): late results are ignored because the item is dropped. No timers here (the synth timeout lives in headtts.ts). Target: under 120 lines. Never log sentence text.
RED: write the test file, run it, confirm it fails, commit `test(05-03): ...`. GREEN: implement, commit `feat(05-03): ...`. Use `git commit -- <paths>`.
  </implementation>
