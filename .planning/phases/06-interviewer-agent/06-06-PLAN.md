Grill request (verified live, research Code Example 1):
`{ model, max_tokens: 1024, output_config: { effort: 'low' }, cache_control: { type: 'ephemeral' }, system: buildSystem(brief), tools: [INTERVIEW_CONTROL_TOOL], tool_choice: { type: 'auto' }, messages: [...grillMsgs, userTurn({ toolUseId: pendingToolUseId, proctor: proctorNote(req, brief), candidate })] }`, options `{ signal }`. No `thinking` field (Opus 5.5 adaptive; disabled/enabled -> 400). Forced tool_choice -> 400.
Stream loop: `for await (const ev of stream) if (ev.type==='content_block_delta' && ev.delta.type==='text_delta') yield {type:'text', delta: ev.delta.text}`; then `const msg = await stream.finalMessage()`.
Usage mapping: `{ inputTokens: u.input_tokens, outputTokens: u.output_tokens, cacheRead: u.cache_read_input_tokens ?? 0, cacheWrite: u.cache_creation_input_tokens ?? 0, stopReason: msg.stop_reason }`.
Extraction (Code Example 2): `client.messages.parse({ model, max_tokens: 2048, output_config: { effort: 'low', format: zodOutputFormat(OpeningPlanSchema) }, system: EXTRACT_SYSTEM, messages: [{ role:'user', content: wrapCandidate(opening) }] }, { signal })` -> `toExtractResult(r.parsed_output)`.
Warm-up: `{ model, max_tokens: 1024, output_config:{effort:'low'}, system: buildWarmupSystem(), messages: [...warmMsgs, userTurn({ proctor: warmupNote(n), candidate })] }` — NO tools, no brief. Never sets warmupComplete (warm-up end is code-owned: skip button or 10-min timer, CONTEXT "Warm-up").
Candidate text for a turn = the last `req.history` entry if its speaker is 'candidate' (for the first grill turn this is the presentation opening — the partner hears it), else none.
SSE wire format for the stub: `event: <type>\ndata: <json>\n\n` per event; response headers `content-type: text/event-stream`. The research spike event order is `message_start, content_block_start(thinking), content_block_delta(thinking_delta ''), content_block_delta(signature_delta), content_block_stop, content_block_start(text), content_block_delta(text_delta)…, content_block_stop, content_block_start(tool_use), content_block_delta(input_json_delta)…, content_block_stop, message_delta(stop_reason tool_use, usage), message_stop`.
