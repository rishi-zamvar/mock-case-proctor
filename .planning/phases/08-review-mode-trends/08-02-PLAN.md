    numberChecks (tokens = case_99 numberTokens). Window = 6 normalised words either side of the mention; METRIC_KEYWORDS (word → token-id regex): arr→/arr/, grr|gross retention→/grr/, nrr|net retention→/nrr/, growth|growing→/growth|cagr/, margin→/margin|gm/, price|valuation|pre-money|post-money|pre|post→/pre|post|price|val/, multiple|times→/mult/, cagr→/cagr/, burn→/burn/.
    | line | expected row |
    |---|---|
    | "GRR is 85%" | {claim:'85%', matched:'85%', expected:null, correct:true} |
    | "GRR is about 95%" | {claim:'95%', matched:null, expected:'85%', correct:false} |
    | "ARR of $10 million" | correct:true, matched '$9.9M' (1.0% off, inside 2%) |
    | "net retention is 104%" | correct:true |
    | "trading at 4.1x" with "multiple" nearby | correct:true |
    | "we met 3 times last week" | correct:'unverifiable' (no metric keyword with a compatible aliased token) |
    | "I'd say 12 people" | 'unverifiable' |
    Rules: among aliased tokens (ids matching the keywords in the window) with a compatible unit, correct iff any matches; wrong → expected = the closest aliased token text by relative difference. No aliased compatible token → 'unverifiable'. Only candidate lines are passed in by callers. Each mention → one row, in transcript order.

    ledWithCall: first sentence = text up to the first [.!?] followed by whitespace; call words /\b(invest(ing)?|pass|at a price|buy)\b/i must appear within the first 20 words of that sentence.
    | "I'd pass at this price, because…" | true |
    | "Fixturely sells widgets. I'd invest." | false (call not in first sentence) |
    | 25 filler words then "invest" in one sentence | false |
    | "Invest at a price." with recommendation 'unclear' | false (extraction found no call: veto) |
    | "" | false |

    brevityRows: candidate turns in presentation or grilling with ms defined → {turnId, ms, band: brevityBand(ms)}; 45_000 → 'ideal', 95_000 → 'flagged'; warm-up turns excluded.

    flagMap: walk controlLog in order; a flag's status is fixed at its FIRST appearance: in flags_hinted → 'hinted'; else in flags_surfaced → 'found'; never → 'missed'. Unknown flag ids ignored. where = templates.join(', '). Output order = brief flag order.
    | surfaced f1 by candidate, later hinted f1 | f1 found |
    | hinted f2 first, later surfaced by candidate | f2 hinted |
    | f3 never | missed |

    verifyQuotes: normalizeForGuard both sides; a quote verifies if its tokens (>= 3) appear contiguously in one line's tokens; returns the first matching line id. Punctuation/case differences still verify ("GRR is 85%, tenured only" vs line "grr is 85 percent tenured only" does NOT verify — digits differ; "grr is 85 tenured" vs "GRR is 85% — tenured" verifies). Quotes of < 3 tokens, empty, or not found count as dropped. Duplicates verify independently.

    bandOf: 30→ready, 26→ready, 25→close, 20→close, 19→another, 0→another.
